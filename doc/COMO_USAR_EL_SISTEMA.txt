═══════════════════════════════════════════════════════════════════
  PROBLEMAS COMUNES Y SOLUCIONES
═══════════════════════════════════════════════════════════════════

┌────────────────────────────────────────────────────────────────┐
│ PROBLEMA: "Puerto 8080 ya está en uso"                        │
├────────────────────────────────────────────────────────────────┤
│ SOLUCIÓN:                                                      │
│   1. Ejecutar: detener-sistema.bat                            │
│   2. O reiniciar la computadora                                │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ PROBLEMA: "PostgreSQL no está corriendo"                      │
├────────────────────────────────────────────────────────────────┤
│ SOLUCIÓN:                                                      │
│   1. Abrir Servicios de Windows (services.msc)                │
│   2. Buscar "postgresql"                                       │
│   3. Clic derecho → Iniciar                                    │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ PROBLEMA: "No se abre el navegador"                           │
├────────────────────────────────────────────────────────────────┤
│ SOLUCIÓN:                                                      │
│   Abrir manualmente: http://localhost:3000                    │
└────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ PROBLEMA: "Error al iniciar"                                  │
├────────────────────────────────────────────────────────────────┤
│ SOLUCIÓN:                                                      │
│   1. Ver los mensajes de error en la consola                  │
│   2. Verificar que Java, Node.js y PostgreSQL estén           │
│      instalados                                                │
│   3. Ejecutar nuevamente: INSTALAR_Y_CONFIGURAR.bat           │
└────────────────────────────────────────────────────────────────┘
